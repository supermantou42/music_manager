# 声笺 MusicManager 0.2.1

0.2.0 的构建因 Windows 临时目录短路径测试比较失败，未发布安装包。0.2.1 修正该测试，正式发布以下更新。

本次更新加入在线搜歌与下载，完善歌词校对、手动覆盖和导出流程。

## 在线搜歌与下载

- 接入网易云、QQ、酷狗、酷我、咪咕、千千、汽水、5sing、Jamendo、JOOX、Bilibili 和 Apple Music 共 12 个源。
- 支持在线试听、批量下载、进度、取消、重试，以及按歌手、来源、时长和码率筛选、表头排序。
- 下载默认存入应用缓存，完成后可加入当前处理列表并统一导出；保留同源元信息及取得的歌词。
- 歌词候选搜索扩展到 10 个源，单条歌词失败可原地重试，不必重新搜索整组。

## 歌词与元信息校对

- 原文件和候选歌词均可独立调整时间轴偏移：精细滑块、±1 秒和 ±0.05 秒按钮；调整区默认折叠。
- 偏移会用于试听高亮、歌词定位、采纳和导出；原音乐文件保持不变。
- 兜底候选整体置顶，组内按匹配分倒序，默认选择最高分。
- 未采纳的建议只提示差异，不提前替换列表里的歌名、歌手和专辑；已保存的手动覆盖仍正常展示。
- 手动覆盖最终输出可直接编辑，无需勾选；覆盖项高亮、加粗，支持回车保存和去重后的搜索备选。
- 修复弹窗焦点导致列表跳动、虚拟列表滚动异常及歌曲播完后不能正常从头重播的问题。
- 搜索参数默认折叠，增加摘要并修复多来源挤窄输入框的问题。

## 导出重构

- 导出前统一选择目录和模式，未设置目录时可快捷选择；显示当前歌曲、阶段及完成进度。
- 默认“单文件”：元信息和歌词写入音频。可选“音频＋LRC”，不再产生旧的 JSON、TXT 或 ASR 附件。
- 可选择不分目录，或用可拖拽参数设计最多 5 级目录、文件名及层级顺序；提供实际路径预览并记忆规则。
- 清空非空目标目录须再次确认，原内容移入系统回收站；回收站失败时停止，不降级为永久删除。源音乐目录与应用目录受到保护。
- 修复 OGG 封面流导致的导出失败，以图片标签保留封面和歌词，无需重编码音频；错误提示显示真正的 FFmpeg 诊断。

## 升级与限制

- 升级保留原用户数据，不会自动改写音乐文件或重新执行扫描、ASR、下载和导出。
- 以前下载记录中未保存的在线歌词不会自动补齐；可在处理列表重新搜索或下载。
- 各源实际可用性、音质和歌词取决于平台接口及账号权益；Apple Music 音频仅提供试听，Jamendo 与 Bilibili 当前适配不提供歌词。未提供 DRM 解密。
- 模型和 CUDA 运行库不随安装包分发，沿用本地配置。安装包尚未配置代码签名，Windows 可能提示未知发布者。
