# 使用说明

[返回 README](../README.md)

独立歌曲搜索与下载见 [在线搜歌与下载](online-music.md)。

## 音乐库与批量操作

全量扫描支持 MP3、FLAC、M4A、OGG、WAV、Opus 和 AAC，跳过符号链接。扫描显示枚举和读取进度，单文件失败不终止整个扫描。文件路径、大小和修改时间未变时，保留历史识别与人工选择。

列表支持按歌曲、歌手、专辑排序，按差异、替代结果、重复版本、ASR 状态或排除状态筛选。虚拟列表最多保留 50 条活跃行；全选覆盖全部筛选结果，跨滚动和筛选保留勾选。

“待复核”在本次审阅期间继续显示已处理歌曲，标记“已处理 · 本次保留”。切换筛选后重新进入，才按最新状态更新范围。

工作区自动记忆筛选、排序、选择、滚动锚点、详情、候选页及试听位置。重开不会自动播放。设置中可调整字体、字号、字重与并发数。

## 歌词核验

ASR 状态与歌词是否匹配分别显示。未识别、排队、识别中、完成及错误均有状态提示；部分片段失败时保留正常结果。正常提交默认跳过已识别歌曲，重试异常时复用成功片段。

歌词对比页左右展示原歌词与切片转写。时间来自原曲中的片段起点，可能跨句并受伴奏影响，目前不能据此自动确认原 LRC 是否整体偏移。

相似度忽略时间戳、标点和作词/作曲等署名。有有效 ASR 与 LRC 时，尝试从首个有效识别片段前两秒开始比较；无时间轴交集时回退全文。

双语评分支持同时间戳原文/译文、部分行内双语和无时间戳的交替排列。仅在文字体系明确、排除疑似译文后得分至少 75% 且提高至少 10 个百分点时采用该分数。分时演唱的混合语种保留全文；同一文字体系的不同语言不强行区分。处理只影响评分，不删除歌词。

历史分数可在打开详情时用已有转写重算，无需重新识别或联网。ASR 不能鉴别歌手声音身份，语种标签也仅供辅助判断。

## 在线候选与元信息编辑

先检索“歌名＋歌手”，没有高相似度结果再降级为仅歌名。搜索页可修改参数并按回车重新搜索；参数不直接修改标签。

候选按综合推荐分排序，时长误差不超过一秒是强匹配信号，但仍需检查版本、歌手和歌词。最高分可能带有“需复核”提示；没有有效歌词的高分结果不能直接作为歌词替代。ASR 失败时，原歌词一致且时长误差小于一秒的候选可作为兜底依据。

画廊左侧显示原文件，另外两侧显示可切换的在线候选，并同步显示歌词进度。播放的是本地原曲，尚未提供在线候选录音试听。点击歌词跳转；手动滚动后三秒内暂停自动跟随。

元信息详情支持直接输入，以及选取去重后的歌名、歌手、专辑值；整组填入只更新这三个字段。更多字段可覆盖歌词及自定义文本标签。封面支持原封面、无封面和候选缩略图。

## 导出优先级

| 顺序 | 规则 |
| --- | --- |
| 1 | 整首排除，或重复审阅中未保留的版本，不导出 |
| 2 | 明确使用原信息时忽略候选；否则优先手选候选，再使用可用歌词候选中的最高分结果 |
| 3 | 没有可用候选时使用原信息 |
| 4 | 在选定信息上应用手动覆盖，得到最终字段 |

手动覆盖只作用于已选字段，显式空值表示清空；恢复默认则继承来源值。更换候选不会清除其他手写字段。列表显示最终输出字段及来源标记。

点击导出后，先在弹窗选择输出目录和模式，未设置目录时可直接选择。默认“单文件”：元信息与歌词写入音频；“音频＋LRC”：元信息写入音频，歌词单独保存为同名 LRC，音频内不保留歌词。不再生成 JSON、TXT 或 ASR 附件。手选封面写入输出副本，“无封面”移除封面；写入失败会报告并移除本次不完整的副本。导出进度显示当前歌曲、阶段和完成数量。相同字节文件在批次内去重，已有输出不直接覆盖。

“清空目标目录”默认关闭。目标非空时会显示目录和现有项目数量，需再次确认；原内容通过桌面客户端移入系统回收站，可从回收站恢复。回收站操作失败时停止导出，不降级为永久删除。目标目录不能包含资料库源文件；不允许清空磁盘根目录、用户目录或应用目录。

## 试听与重复版本

桌面端使用 mpv 与 WASAPI 共享输出；浏览器模式使用 HTML5 audio，必要时生成 PCM WAV 兼容缓存。

重复版本审阅可以保留一个或多个版本。A/B 预加载两份音频，共用时间与音量，切换时校准位置；不承诺采样级无缝，不自动归一化响度。

波形采用单个叠加视图，默认三秒窗口，可缩放与跟随。窗口 MSE 比较幅度轮廓，不能直接作为音质评分。重复分组基于标签和时长推测，尚未使用音频指纹。

## 数据与快捷键

下表为开发版路径。安装版将 `data/` 对应到 `%APPDATA%\MusicManager/`，升级保留该目录。

| 路径（相对项目根目录） | 内容 |
| --- | --- |
| `data/library.json` | 音乐库、识别、候选与审阅结果 |
| `data/settings.json` | ASR 与接口并发配置 |
| `data/workspace-state.json` | 界面位置与状态 |
| `data/asr/` | 切片 WAV、粗 LRC、片段索引 |
| `data/model-service/` | 模型服务日志 |
| `data/audio-preview/`、`data/waveform-cache/` | 试听与波形缓存 |

在线搜索向所选平台发送歌名、歌手；音频、路径与 ASR 转写保留在本地。运行数据不提交 Git。

快捷键：`Ctrl+F` / `Ctrl+K` 搜索，`Ctrl+,` 设置，`Esc` 关闭当前面板。开发版标题栏另有调试菜单，可重载、打开开发者工具与重启客户端。

### 候选歌词时间偏移

有时间戳的候选卡片可拖动“歌词出现时间”滑块，向左让歌词提前出现，向右让歌词延后出现，支持 0.05 秒步进；点击“应用偏移”或在输入框中按回车保存。滑块围绕当前值提供 ±2 秒微调范围，松手后重新居中，可连续拖动；另有 ±1 秒和 ±0.05 秒按钮，总偏移限制为 ±600 秒；点击“恢复原时间”恢复原时间轴。试听高亮、歌词定位和候选导出使用调整后的时间戳；修改偏移不会自动采纳候选。单条重新获取歌词后会继续应用已保存偏移。手动覆盖的歌词仍优先于候选歌词。

原文件和候选卡片的“◷ 时间轴”默认收起，展开后可各自调整。原文件歌词偏移只修改当前处理数据与导出结果，不改写源音乐文件；选择原信息导出时使用调整后的原歌词。

### 目录结构与文件名

导出弹窗可选“分目录”或“不分目录”。分目录最多 5 级，默认是 `{artist}` → `{album}`；各级名称可拖入参数，也可输入固定文字，层级可拖动排序或用上移按钮调整。选择“不分目录”时所有输出直接放在目标目录中。

文件名默认 `{title}`，可改为 `{artist} - {title} [{format}]` 等组合，扩展名自动保留。可用参数包括歌名、歌手、专辑、专辑歌手、年份、流派、曲目编号、碟片编号、格式和码率；参数可拖入或点选插入。缺少的字段显示“未知”，Windows 非法文件名字符会被替换。规则随界面偏好保存。

预览按所选歌曲的最终导出信息生成。单文件模式每个目录仅保存音频；分离模式在相同目录保存音频及同名 LRC。已有同名文件不会覆盖，命名冲突会报告，可在导出前调整规则。
