# 在线搜歌与下载

从左侧“在线搜歌”进入，输入歌名或歌手，选择音乐源后按回车搜索。结果保留来源、专辑、时长和平台提供的音质信息；某个源失败不会清空其他源的结果。

歌手和来源筛选项由本次搜索结果去重生成，并显示数量。时长按一分钟分段（含下限、不含上限），码率按常用档位分段（不含下限、含上限），仅显示有结果的区间；未知值可单独筛选。点击列表表头的歌手、来源、时长或平台音质，可依次切换升序、降序和默认顺序。全选和批量下载仅作用于筛选后结果，隐藏的已选歌曲保留勾选并显示数量。

## 音乐源

| 源 | 下载能力 |
| --- | --- |
| 网易云音乐、QQ 音乐、酷狗音乐、酷我音乐 | 平台可用音频，默认参与搜索 |
| 咪咕音乐、千千音乐、5sing、Jamendo、JOOX、Bilibili | 平台可用的独立音频直链 |
| 汽水音乐 | 未加密的音频直链；加密资源不下载 |
| Apple Music | 仅试听片段 |

适配基于 [music-lib v1.1.1](https://github.com/guohuiyuan/music-lib/tree/v1.1.1)，对应提交 `6353508e84cd357b5bc3acf32d95a16e01bbe20c`。可用性、音质与完整性受平台接口、地区和账号权益影响。当前不提供扫码登录或 DRM 解密。

## 下载与试听

搜索结果的播放按钮可直接在线试听，无需选择下载目录。音频边加载边播放，支持底部播放器暂停、继续和拖动进度；平台仅提供片段时会提示。试听不会加入下载记录或保存到输出目录。

1. 默认下载到应用数据目录下的 `download-cache` 临时目录，也可以选择其他下载目录。
2. 单首点击下载，或勾选结果后点击“下载所选”。全选覆盖本次全部搜索结果。
3. 在“下载记录”中查看进度、取消、重试或试听。下载完成后点击“加入处理列表”，歌曲会追加到当前列表并自动勾选，可一起核验和导出；重复点击不会重复添加。

最多两首同时下载，额外任务排队。关闭搜歌面板不会停止任务；退出客户端会中断下载，重开后需重试。搜索结果保留三十分钟，过期或重启后需重新搜索。

文件按“歌手 - 歌名”保存；已有同名文件添加数字后缀，不覆盖。试听片段在界面和文件名中标记。完成后显示检测到的实际格式、时长与码率，并可使用现有播放器试听。

返回的音频会经过文件头与 FFprobe 检查；错误页、播放列表、不完整响应和非独立音频不会作为成功结果保存。每首最大 1 GiB，失败或取消清理临时文件。加入处理列表后，临时音频会作为导出源保留，重启仍可继续处理；重新扫描原目录也会保留已加入的下载歌曲。

下载记录保存在开发版 `data/downloads.json`，安装版为用户数据目录中的 `downloads.json`。

## 可选登录信息

平台 Cookie 通过启动客户端前的环境变量传入：`MUSIC_<源ID大写>_COOKIE`，例如 `MUSIC_NETEASE_COOKIE`、`MUSIC_QQ_COOKIE`、`MUSIC_BILIBILI_COOKIE`。源 ID 见 `src/music-sources.json`。Cookie 不写入下载记录或仓库；会员歌曲仍取决于账号权益。

## 开发验证

构建适配程序需要 Go 1.25+。运行真实接口验证：

```powershell
npm run build:metadata
node scripts/verify/verify-online-music.cjs
node scripts/verify/verify-online-music.cjs --download
```

默认搜索 Jamendo、酷我、QQ 和网易云的 `piano`；`--download` 下载一个 Jamendo 结果到本地 `validation/online-music/`。`--all` 查询全部源，`MUSIC_VERIFY_QUERY` 可更改关键词。此验证会联网，不属于 `npm test`。
